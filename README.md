## 0.14.23 변경

- 후원 편지가 오면 “편지가 도착한 느낌이 들어!”라고 캐릭터가 혼자 말합니다.
- 의뢰도 짧은 도착 독백으로 알립니다. 상세 조건은 수첩과 편지에서 확인합니다.
- 여러 후원은 수신 순서대로 알리며 기존 대화를 덮어쓰지 않습니다. 편지 알림은 진행 중인 활동이 끝나기를 기다립니다.
- 퀘스트 물품도 보유 수량만큼 판매할 수 있습니다. 의뢰는 유지되며 부족해진 물건은 다시 모아 납품합니다.
- 상단 API 안내의51 착불 편지 뒤100코인 표기만 제거했습니다. 실제 착불비100코인은 유지합니다.

이전 버전의 SOOP 자동 연결·상자 보상 대화·밤 벌레 소리 감소·가게 상호작용 입장·젖은 밭을 유지합니다. 박물관233종의10단계 보상(전체159,000코인), 빚 전용 청구서·큰 빨간 납부 도장·일반 편지10종도 유지합니다.

## 누락 보정 콘솔

백틱 키로 열고 **123처럼 수량만 입력한 뒤 Enter**를 누르세요. **/api 123**도 지원합니다. 숫자 뒤에는 백틱을 붙이지 않습니다.

지원 수량: 50, 51, 77, 88, 99, 123, 222, 333, 444, 4444.
333·444개로 조정한 담배 가격은 재실행해도 유지됩니다.
