**[최신 Windows 배포판](https://github.com/INTPEDITOR/mint-island-downloads/releases/latest)**

## 0.14.21 변경

- 박물관 233종의 사례를 10단계로 지급합니다. 목표는 10·25·50·75·100·125·150·180·210·233종이며 전체 보상은 159,000코인입니다.
- 기존 기증과 지급 내역을 보존하고 이미 받은 금액을 공제한 차액만 한 번 지급합니다. 느루에게 다음 목표와 전체 단계표를 물어볼 수 있습니다.
- 청구서는 실제 납부할 벌칙 빚과 착불 요금에만 도착합니다. 씨앗·담배 구매 뒤에는 영수증 편지를 보내지 않습니다.
- 청구서 전용 편지지와 새 빨간 납부 완료 도장을 적용했습니다. 납부가 저장되면 원문 위에 큰 도장을 비스듬히 겹칩니다. 본문은 유지합니다.
- 일반 편지 10종, 기존 후원 효과와 보정 콘솔, 합성 바람 잡음 제거를 유지합니다.

## 누락 보정 콘솔

백틱 키로 열고 **123처럼 수량만 입력한 뒤 Enter**를 누르세요. **/api 123**도 지원합니다. 숫자 뒤에는 백틱을 붙이지 않습니다.

지원 수량: 50, 51, 77, 88, 99, 123, 222, 333, 444, 4444.
333·444개로 조정한 담배 가격은 재실행해도 유지됩니다.

## 검증과 조작

소스68개·새 EXE274개, 합계342개 검사를 통과했습니다. 기증233종 지급 경계·기존 저장0~233종 차액·저장 실패 복구·실제 기증/납부 입력·세 해상도·별도 프로세스 재시작과 기존 대사/편지/API를 확인했습니다. SOOP은 독립 모의 세션으로 검사했습니다.

알려진 기존 문제: 벌칙 도착 독백을 읽는 동안에도 벌칙 시간이 흐르는 동작은 이번 업데이트에서 변경하지 않았습니다.

WASD 이동 · Shift 달리기 · E 대화/사용 · F 줍기/수확 · 1~6 도구 · Tab 가방 · M 지도 · P 수첩 · Esc 닫기.

방송 연결은 게임 설정에서 방송국 아이디 또는 주소를 입력합니다.
저작권과 라이선스는 ZIP의 THIRD_PARTY_NOTICES.txt와 licenses 폴더에 있습니다.
