# 어서오세요 송민트의 섬

Windows PC 싱글 플레이 섬 생활 게임입니다.

## 다운로드

**[최신 Windows 배포판](https://github.com/INTPEDITOR/mint-island-downloads/releases/latest)**

[0.14.20 ZIP 바로 받기](https://github.com/INTPEDITOR/mint-island-downloads/releases/download/v0.14.20/MintIsland_v0.14.20_Windows.zip)

ZIP 전체를 압축 해제한 뒤 **MintIsland.exe**를 실행하세요. Godot 설치는 필요하지 않으며 기존 저장 파일을 사용합니다.

## 0.14.20 변경

- 상시 재생되던 합성 바람·풀잎 잡음과 별도 합성 바람 루프를 제거했습니다.
- 123개 선물은 수집품 3~5개를 유지하고, 상자당 꽁초 0.1%(10초 사용)·온전한 담배 0.001%(60초 사용)를 추가했습니다. 최초 지급 장비는 나오지 않습니다.
- 222개 벌칙은 기존 6종에 신규 11종을 더한 17종입니다. 효과 이름과 수치 설명 대신 송민트의 짧은 독백으로 알립니다.
- 메마른 작물은 다시 물을 주면 원래 성장 상태로 살아납니다. 검댕 세수는 제외했습니다.
- 이전 효과음·필터·창 옵션·대상 탐색 최적화도 포함합니다.

## 누락 보정 콘솔

백틱 키로 열고 **123처럼 수량만 입력한 뒤 Enter**를 누르세요. 숫자 뒤에 백틱을 붙이지 않습니다. **/api 123** 형식도 지원합니다.

지원 수량: 50, 51, 77, 88, 99, 123, 222, 333, 444, 4444.

수동 입력도 실제 수신과 같은 저장 경로를 사용합니다. 잘못된 수량·저장 실패·중복 Enter로 효과가 잘못 적용되지 않도록 검사했습니다.

333·444개로 조정한 담배 가격은 재실행해도 유지됩니다. 임시10% 인상은 종료 시각까지 유지된 뒤 그 가격으로 돌아옵니다.

## 검증과 조작

규칙42개·실제 소스 게임50개·새 EXE 기능51개·기본 실행/저장31개·가격 재실행5개 검사를 통과했습니다. 실제10/60초 흡연·3초 도구 준비·20초 말벌 추격과 야외 믹서 녹음을 확인했습니다. SOOP 이벤트는 독립 모의 세션으로 검사했습니다.

WASD 이동 · Shift 달리기 · E 대화/사용 · F 줍기/수확 · 1~6 도구 · Tab 가방 · M 지도 · P 수첩 · Esc 닫기.

방송 연결은 게임 설정에서 방송국 아이디 또는 주소를 입력합니다.

저작권과 라이선스는 ZIP 안의 THIRD_PARTY_NOTICES.txt 및 licenses 폴더에 있습니다.
