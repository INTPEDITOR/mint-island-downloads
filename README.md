# 어서오세요 송민트의 섬

Windows PC 싱글 플레이 섬 생활 게임입니다.

## 다운로드

**[0.14.22 Windows ZIP 받기](https://github.com/INTPEDITOR/mint-island-downloads/releases/download/v0.14.22/MintIsland_v0.14.22_Windows.zip)**

[최신 릴리스](https://github.com/INTPEDITOR/mint-island-downloads/releases/latest)

ZIP 전체를 압축 해제한 뒤 **MintIsland.exe**를 실행하세요. Godot 설치는 필요 없으며 기존 저장을 사용합니다.

## 0.14.22 변경

- SOOP의 정상 숫자 응답을 잘못 거절하던 연결 오류와 API 주소를 수정했습니다.
- 방송국 아이디만 입력하고 1초 기다리면 자동 연결합니다. Enter로 즉시 연결할 수도 있습니다.
- 방송 정보 요청을 작업 스레드로 옮기고 타이핑 중 중복 연결과 창 닫기 뒤 예약 연결을 막았습니다.
- 해변 보물상자와 후원 선물상자의 보상을 기존 대화창에서 품목·수량으로 알려줍니다.
- 밤 벌레 환경음만 낮췄습니다.
- 가게는 야외 문 앞에서 E로 입장하며 나올 때는 기존처럼 자동 퇴장합니다.
- 물 준 밭의 흙색이 짙어지고 저장 후에도 유지됩니다.

박물관 233종의 10단계 보상(전체159,000코인), 빚 전용 청구서·큰 빨간 납부 완료 도장·일반 편지10종을 유지합니다. 씨앗·담배 구매 뒤 영수증 우편은 보내지 않습니다.

## 누락 보정 콘솔

백틱 키로 열고 **123처럼 수량만 입력한 뒤 Enter**를 누르세요. **/api 123**도 지원합니다. 숫자 뒤에는 백틱을 붙이지 않습니다.

지원 수량: 50, 51, 77, 88, 99, 123, 222, 333, 444, 4444.
333·444개로 조정한 담배 가격은 재실행해도 유지됩니다.

## 검증과 조작

소스49개·새 EXE49개·기존 편지/그래픽/API 회귀82개, 총180개 검사를 통과했습니다. 실제 입력·저장 실패 복구·별도 프로세스 재시작을 확인했습니다. 수정된 Godot 코드로 실제 SOOP 채팅방 입장을 확인했으며 실제 별풍선 수신은 별도 미검증입니다.

고정 장면의 연결 끔/실패 재시도 비교에서 프레임p95는 모두 약16.8ms였고 50ms 초과 프레임은 없었습니다. 사용자 환경의 모든 버벅임 해결을 뜻하는 측정은 아닙니다.

알려진 기존 문제: 벌칙 도착 독백을 읽는 동안에도 벌칙 시간이 흐릅니다.

WASD 이동 · Shift 달리기 · E 대화/사용 · F 줍기/수확 · 1~6 도구 · Tab 가방 · M 지도 · P 수첩 · Esc 닫기.
